# Consult Change - Professional Website

A modern, responsive one-page website for Consult Change - Legal Operations, Technology & Organizational Transformation consultancy.

## 🎨 Design Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile
- **Dual Language Support**: English/Polish toggle functionality
- **Professional Branding**: Custom logo with brand color palette
- **Smooth Animations**: Interactive hover effects and scroll animations
- **Modern UI**: Clean, consultancy-appropriate design

## 📋 Sections

1. **Hero Section**: Compelling value proposition with clear CTAs
2. **Services**: Six core expertise areas including CLM/ELM transformation
3. **Team**: Detailed profiles of consultants with specializations
4. **About**: Methodology and proven results
5. **Contact**: Contact form and Calendly integration

## 🚀 Deployment Instructions

### For home.pl hosting:
1. Upload `index.html` to your domain's public folder
2. Upload `your-photo.jpg` (professional headshot)
3. Set up domain redirect: consultchange.eu → consultchange.pl

### For other hosting:
- Any web server supporting static HTML files
- No backend requirements - pure frontend solution

## ⚙️ Setup Requirements

### Required files:
- `index.html` (main website file)
- `your-photo.jpg` (professional photo - 400x400px recommended)

### Optional integrations:
- **Calendly**: Replace `#` with your booking URL
- **Contact Form**: Connect to form handler service (Formspree, Netlify Forms, etc.)
- **Analytics**: Add Google Analytics or similar tracking
